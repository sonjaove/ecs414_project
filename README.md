# ECS 414 Stock Correlation Network

This repository contains the code and data for an ECS 414 Network Sciences
project. It constructs an unweighted stock-correlation network from NSE Nifty
stock price data and studies its network properties.

The analysis includes:

- cleaning adjusted-close price data and calculating log returns;
- calculating Pearson correlations between stocks;
- creating an unweighted network by thresholding absolute correlations;
- comparing network properties across correlation thresholds;
- degree-distribution analysis;
- degree, betweenness, and eigenvector centrality;
- local clustering coefficients; and
- sector-based visualization and sector homophily (assortativity).

## Repository structure

| File | Description |
| --- | --- |
| `crawl_prices.py` | Downloads approximately three years of daily adjusted-close prices for Nifty 100 stocks from Yahoo Finance. |
| `creating_nw.py` | Cleans prices, calculates log returns and correlations, and creates an unweighted adjacency matrix. |
| `analysis.py` | Loads the network data, calculates network statistics, creates plots, and saves results. |
| `rough.ipynb` | Notebook used for interactive exploration. |
| `nifty100_adjusted_close.csv` | Adjusted-close price data for the Nifty 100 stocks. |
| `nifty500_adjusted_close.csv` | Alternative adjusted-close price dataset. |
| `unweighted_adjacency_matrix_nifty100.csv` | Adjacency matrix used by `analysis.py`. |
| `unweighted_adjacency_matrix.csv` | Adjacency matrix generated by `creating_nw.py` unless the output filename is changed. |

Generated files such as correlation matrices and analysis results are not
required to be committed to the repository.

## Requirements

Python 3.9 or newer is recommended. Install the required packages with:

```bash
python -m pip install pandas numpy yfinance requests networkx seaborn matplotlib jupyter
```

## How to run

Run commands from the repository root.

### 1. Download price data

To download fresh Nifty 100 data:

```bash
python crawl_prices.py
```

This creates or replaces `nifty100_adjusted_close.csv`. The script uses the
NSE Nifty 100 list and Yahoo Finance, so an internet connection is required.

### 2. Create the correlation and network data

Run:

```bash
python creating_nw.py
```

The script:

1. removes stocks with more than 20% missing prices;
2. calculates log returns;
3. calculates Pearson correlations using at least 60 overlapping observations;
4. uses an absolute-correlation threshold of `0.2`;
5. removes self-connections; and
6. writes `correlation_matrix.csv` and `unweighted_adjacency_matrix.csv`.

By default, `creating_nw.py` reads `nifty500_adjusted_close.csv`. To analyze
the Nifty 100 dataset instead, change its input line to:

```python
df = pd.read_csv("nifty100_adjusted_close.csv")
```

To use the generated adjacency matrix with `analysis.py`, either rename or
copy it to `unweighted_adjacency_matrix_nifty100.csv`, or update the input
filename at the beginning of `analysis.py`.

### 3. Run the network analysis

After the required correlation and adjacency files are available, run:

```bash
python analysis.py
```

The script also downloads the current NSE sector list to assign an industry
sector to each graph node. An internet connection is therefore required for
sector-colored plots.

The first network plot and the sector homophily plot use the same stock
correlation graph. The former emphasizes degree and the most connected stocks,
while the latter repeats the network with nodes colored by sector and reports
the sector assortativity coefficient. The homophily plot does not create a
separate network or aggregate stocks into sector nodes.

The analysis may take some time because it calculates betweenness centrality,
eigenvector centrality, clustering coefficients, multiple threshold networks,
and high-resolution plots.

## Output files

`analysis.py` creates a `results/` directory containing:

### Tables

- `threshold_comparison.csv` — network statistics for thresholds from 0.1 to 0.9.
- `degree_distribution.csv` — degree of every stock.
- `degree_statistics.csv` — average, median, minimum, and maximum degree.
- `centrality_leaderboard.csv` — degree, betweenness, and eigenvector centrality.
- `clustering_coefficients.csv` — clustering coefficient for every stock.
- `sector_counts.csv` — number of stocks in each sector.
- `network_summary.txt` — key summary statistics.

### Figures

- `nifty100_sector_network.png`
- `threshold_metrics.png`
- `degree_histogram.png`
- `degree_log_log_distribution.png`
- `top10_centrality_leaderboard.png`
- `top15_clustering_coefficients.png`
- `nifty100_network_by_industry_sector.png`

Figures are saved as PNG files at 300 DPI. The degree plots include average
and median degree reference lines, and the clustering plot includes the
network-wide average clustering coefficient.

## Reproducibility notes

- The price and sector data are downloaded from external services and may
  change over time.
- The network layout uses fixed random seeds where applicable, making the
  visual layout repeatable for the same input data.
- The correlation threshold, missing-data limit, and minimum observations can
  be changed in `creating_nw.py`.
- Run the scripts from the repository root so relative file paths resolve
  correctly.
